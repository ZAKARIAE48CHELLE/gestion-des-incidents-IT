Docker Compose — Lancement unifié

Un seul fichier pour démarrer les 5 services + 5 bases de données

🐳 docker-compose.yml incident-system/
Commandes utiles
$ docker-compose up --build # Démarrer tous les services
$ docker-compose up ms2-affectation ms3-utilisateurs # Démarrer 2 services
$ docker-compose logs -f ms2-affectation # Voir les logs d'un service
$ docker-compose down -v # Tout stopper + supprimer volumes
